# 🇮🇳 MPLADS Insight — AI-Powered Development Monitoring & Analytics

**Transforming public development data into transparent, data-driven insights.**

MPLADS Insight is an AI-powered monitoring and analytics platform designed to help visualize, analyze, and track development works under the **Members of Parliament Local Area Development Scheme (MPLADS)**.

The platform aims to improve transparency, accessibility, and data-driven decision-making by presenting development project information through an intuitive dashboard, interactive visualizations, and intelligent analytics.

## 🚀 Project Overview

Monitoring public development works can be challenging when project information is scattered across multiple sources or presented in formats that are difficult to interpret.

MPLADS Insight aims to address this challenge by providing a centralized digital interface for exploring project information, monitoring development progress, analyzing fund utilization, and identifying potential implementation gaps.

## ✨ Key Features

- **📊 Interactive Dashboard** — A centralized overview of development projects and key performance indicators.
- **📍 Project Monitoring** — Explore development works by state, district, constituency, and project category.
- **💰 Fund Utilization Analytics** — Visualize allocated, released, and utilized funds wherever verified data is available.
- **🤖 AI-Powered Insights** — Designed to support data-driven summaries, trend analysis, and potential anomaly detection.
- **📈 Data Visualization** — Present project statistics and development trends through charts and graphs.
- **🔎 Smart Filtering** — Filter projects using relevant geographical and administrative parameters.
- **🌐 Responsive UI** — A modern interface designed for desktop, tablet, and mobile devices.
- **🔍 Transparency-Oriented Design** — Make development information easier to explore and understand.

- Install the **Live Server** extension.
- Right-click `index.html`.

## ⚠️ Data & Transparency Disclaimer

MPLADS Insight is an independent technology project intended for analytical and informational purposes. It is not an official government platform and is not affiliated with the Ministry of Statistics and Programme Implementation or any government authority.

Any displayed statistics, project statuses, and financial figures should be verified against reliable official sources. AI-generated insights are analytical aids and should not be treated as verified allegations of irregularities or misuse of funds.
